# Web to APK Builder

GitHub Actions를 이용해 웹사이트를 Android WebView APK로 빌드하는 프로젝트입니다.

현재 기본 앱:
- 앱 이름: 힘박스 영상제작기
- 시작 URL: https://music.lightsalt2.com/영상-제작/
- 패키지: com.hymnbox.video

## APK 만들기
1. GitHub 저장소의 Actions 탭을 엽니다.
2. Build Android APK 워크플로를 선택합니다.
3. Run workflow를 누릅니다.
4. 완료 후 Artifacts의 hymnbox-video-apk를 다운로드합니다.
